# A 系 — 写作风格规则

本文件定义 thesis skill 写出每一句中文必须遵守的写作规则。规则编号 A.x 与 `rules-index.md` 一致。hook 通过 `thesis_docx_audit.py` 对部分项做硬检查（对应 G 系 ID 见 `rules-index.md`）。

> **范围说明**：本文件只管"句子怎么写"。引用规范见 `gbt7714-format.md`（C 系）。章节标题"一节一论点"见 `outline-rules.md` Rule B.1。具体字号字体不在本文件，见 `format-rules.md`（E 系）从用户提供的范文/模板抓取。

---

## A.1 禁用表达（零容忍）

下列表达是 AI 写作指纹，**任何场景都不得出现**。被 G.x hook 命中时 violation 阻断。

### A.1.1 顺序枚举词
- 首先……其次……再次……此外……
- 第一……第二……第三……
- 一方面……另一方面……

**替代**：让逻辑由内容推动。要列举三件事就直接陈述三件事，不需要"首先/其次/再次"做信号灯。

### A.1.2 模板引子
- 从……方面 / 从……角度 / 从……层面 / 从……视角出发
- 从……看 / 从……上看 / 从……来看
- 在……背景下 / 在当今社会 / 在当前形势下

**替代**：把视角融入陈述本身。"从经济角度看，这项政策有效" → "这项政策在经济效应上有效"。或直接以事实开头省去引子。

### A.1.3 空意义宣称
- ……具有重要意义
- ……具有深远影响
- ……具有重要的理论价值和实践意义
- ……对……具有重要的指导作用

**替代**：用具体证据展示意义。"本研究具有重要意义" → "本研究填补了 X 领域在 Y 条件下的实证空白"。

### A.1.4 空洞开头
- 随着……的发展 / 推进 / 深入
- 众所周知 / 不可否认 / 毋庸置疑
- 近年来，随着……

**替代**：开篇句必须携带实质信息——具体事实、发现、矛盾或问题。

### A.1.5 机械总结词
- 综上所述（全文末尾可用一次，章节内禁用）
- 总而言之 / 由上可知

**替代**：让结论从最后一个分析点自然落地。如确需总结，用具体术语而非通用模板。

### A.1.6 过度对冲
- 在一定程度上 / 可能在某种意义上 / 或许可以认为

**替代**：仅在认知上确实需要保留余地时使用。学术精确 ≠ 表达模糊。

## A.2 句式多样

A.2.1 连续 3+ 句不得使用同一语法结构（主谓宾单调禁止）
A.2.2 连续段落开头不得相同（同一连接词、同一句式）
A.2.3 长短句交替：陈述与分析交错；不要每段都是匀速中长句
A.2.4 不堆砌排比、比喻、感叹；偶尔用即可
A.2.5 不使用过度对仗的并列结构（"A 是……，B 是……，C 是……"是 AI 标志）

---

## A.3 学术严谨

A.3.1 保持学术语域，不口语化（不得为追求"自然"把"显著性水平"改成"差不多达到的程度"）
A.3.2 保留专业术语与定义；术语第一次出现时给出定义或英文原词括注
A.3.3 引用必须可验证，禁止编造作者、年份、刊名、机构名、政策文件、实验结论
A.3.4 信息不足时显式声明"现有材料不足以判断"或"原文未说明"，不得用模糊语句填空
A.3.5 概念边界清晰：不要把"相关性"和"因果性"混用、不要把"显著"用作日常副词

---

## A.4 不增不减

A.4.1 改写不得新增任何原文未给出的事实、数据、引用、结论
A.4.2 改写不得删减原文已陈述的核心论点、关键数据、限定条件
A.4.3 允许的修改：改语序、换措辞、合并/拆分句子、调整段落分块
A.4.4 拿不准的内容向用户明确询问，不擅自补全

---

## A.5 避免绝对化

A.5.1 禁用绝对化措辞：必然 / 毫无疑问 / 绝对 / 一定会 / 完全证明 / 永远
A.5.2 限定表达替代：在 X 条件下 / 就现有证据而言 / 倾向于支持 / 多数情况下
A.5.3 例外：原文/原数据本身就是绝对结论时按原样保留，不替用户软化

---

## A.6 CJK 数字与西文间距（hook G 系硬检查）

中文字符与相邻英文字母或阿拉伯数字之间**禁止插入空格**。LLM 几乎总会插入此类 pangu 间距，是中文学术写作的典型 AI 指纹。

**作用域：仅正文段落**。以下区域不适用此规则（hook 已排除）：
- 标题行（Heading 1/2/3 段落，含 `# 1 绪论` `## 1.1` `### 1.1.1`），标题序号与文字间的 1 字符空白是格式要求
- 参考文献区域（`## 参考文献` 或对应 docx 标题之后），文献题目保留原始格式
- 图题文本（含编号与标题间的空格）

**正文中禁止**：
- `茶园 IoT 系统` → `茶园IoT系统`
- `Spring Boot 3 框架` → `Spring Boot 3框架`（注意：英文词内部空格如 `Spring Boot`、`Vue 3` 必须保留）
- `第 3 章` → `第3章`
- `共 50 亩` → `共50亩`

**hook 扫描模式**：`[一-鿿]\s+[A-Za-z0-9]` 与 `[A-Za-z0-9]\s+[一-鿿]`，仅在排除上述区域后扫描。

## A.7 em dash（—）禁用（hook G 系硬检查）

字符 `—`（U+2014，em dash）在论文正文中**全面禁用**。AI 偏好用 em dash 做"戏剧化"连接（A—B—C—D），是强 AI 指纹。

**替代**：
- 列举：`A、B、C`
- 因果链：`A 到 B`
- 插入语：拆成两句，用句号
- 直接引语：用冒号或重写

**例外**：英文参考文献题名中的原文 `—` 或 `–`（en dash）允许保留，因为是源文本引用而非正文作者表达。hook 仅扫描 `## 参考文献` 之前的正文区域。

## A.8 人类写作特征（建议）

下列特征不强制（hook 不检查），但应主动模仿，让产出像人写的：

A.8.1 段落开头多样化：以发现 / 对比 / 问题 / 引用前人 / 数据点 等不同入口切入
A.8.2 自然过渡：靠最后一句和下一句的概念衔接，不靠"因此/然而"等转折词扛活
A.8.3 偏向具体：宁可 "Wolfert 等(2017) 在欧盟 280 个农场的数据上发现 X" 也不要 "已有研究表明 X"
A.8.4 学术个性：真研究者会说"令人意外的是" / "与 X 的结论相反" / "此处常被忽视的是"
A.8.5 深度不均：主要论点详细分析，支撑点可一句带过；AI 倾向所有点等量齐观
A.8.6 偶发复杂句：真学术句子有时会嵌套从句，不要每句都简化为主谓宾

## A.9 中文标点（hook G 系硬检查）

正文段落中**必须**使用中文全角标点，禁止使用英文半角标点。

### 替换映射
| 英文（禁） | 中文（用） |
|-----------|-----------|
| `,` | `，` |
| `.` | `。` |
| `;` | `；` |
| `:` | `：` |
| `!` | `！` |
| `?` | `？` |
| `(` `)` | `（` `）` |

### 例外（不算违规）
- 引用编号 `[1]`、`[2]`...：GB/T 7714 强制方括号格式，必为半角
- 英文术语内部：`UTF-8`、`Wi-Fi`、`Spring Boot`、`Vue 3`（连字符、版本号、英文词中的点）
- 数字章节号：`1.1`、`3.2.1`（数字+点+数字模式）
- 英文段落（Abstract、Key words 节）整段保留英文
- 参考文献节（`## 参考文献` 或对应 docx 标题之后）：GB/T 7714 混合标点格式
- URL：`https://...`
- 邮箱：`a@b.com`
- 英文人名缩写：`Wolfert S. J.`、`Smith J.`

### 作者-年份标注：必须全角
本规则联动修订 C.2：`Wolfert 等(2017)` → `Wolfert 等（2017）`，`刘美琼(2024)` → `刘美琼（2024）`。半角括号包年份在正文中**视为违规**。

### hook 扫描模式（G.20）
- `[一-鿿][,;:!?]` 中文后接英文标点
- `[,;:!?][一-鿿]` 英文标点后接中文
- `[一-鿿]\)` 中文后接英文右括号
- `\([一-鿿]` 英文左括号后接中文
- `[一-鿿]\.(?!\d)` 中文后接英文句号（排除 1.1 类章节号）
- `\((?:19|20)\d{2}\)` 半角括号包 4 位年份（视为作者-年份违规）
