# C 系 — 引用规范

本文件合并了**所有引用相关规则**：引用使用约束（C.1-C.7，原 anti-ai-patterns.md 的 Citation Rules）+ GB/T 7714-2015 条目格式（C.8-C.13）。规则编号 C.x 与 `rules-index.md` 一致。多数项被 hook 通过 `thesis_docx_audit.py` 硬检查。

---

## C.1 引用编号按首次出现升序（hook G 系硬检查）

正文中引用编号 `[N]` 必须按首次出现顺序严格递增：`[1]`, `[2]`, `[3]`, ...，**不得乱序**。参考文献列表顺序与正文首次出现顺序一致。

### 正例
首次 `[1]` 在 1.3，再 `[2]` 在 1.3.1，再 `[3]` 在 1.3.1，...，`[N]` 在后续章节。

### 反例
首次 `[5]` 在 1.2，再 `[1]` 在 1.3.1 → 乱序，违反 GB/T 7714 编号约定。

### 重复引用
某条文献已分配编号后，后续每次出现仍用同一编号（如 `[1]` 可在 1.2 和 1.3.1 都出现，因为是同一文献——但本规则被 C.5 覆盖）。

### 未引用文献
参考文献列表中存在但正文未引用的条目违规。每条文献必须至少在正文中被引用一次。

## C.2 作者姓名后必须紧贴（年份）（hook G 系硬检查）

正文**提及作者姓名**时，作者名后必须**立即跟（年份）**，年份与参考文献条目一致。中英文作者通用。

> **2026-05-08 修订**：括号必须用全角 `（）`，**不再接受半角** `()`。原因：联动 A.9 中文标点规则——正文中所有标点必须中文全角。半角作者-年份标注现视为违规。

### 正例
- `刘美琼（2024）在福建茶园生态管理规模效益研究中指出，精细化的生态参数……[2]`
- `Wolfert 等（2017）对智慧农业中的大数据应用做了系统综述……[12]`
- `黄伟红等（2024）把间作绿肥这一传统农艺与现代生态系统评估结合……[9]`

### 反例
- `刘美琼在福建茶园生态管理规模效益研究中指出……[2]` — 缺（2024）
- `Wolfert 等对智慧农业……做了综述[12]` — 缺（2017）
- `刘美琼(2024)...` — 半角括号违规（A.9 + C.2 双违）

### 规则细则
- C.2.1 首次提及：`作者（年份）`，**必须全角括号**，半角 `(年份)` 视为违规
- C.2.2 中文作者用全名：`刘美琼（2024）`、`李宏（2024）`、`黄伟红等（2024）`（多作者用"等"）
- C.2.3 西文作者用姓：`Wolfert 等（2017）`、`Gong 等（2024）`
- C.2.4 年份**必须等于**参考文献条目的年份
- C.2.5 同一节内重复提及同一作者：第二次起年份可省略
- C.2.6 跨节再次提及：年份**必须**重复

> **为什么混合引用**：本科论文用作者-年份 + 编号混合样式，读者不翻文末就能定位文献时代，同时保留 GB/T 7714 编号体系。
> **为什么全角**：A.9 规定正文标点必中文全角；半角括号属违规。

## C.3 一句一引用（hook G 系硬检查）

单句（以 `。` 结尾）**至多一个 `[N]` 引用**。`[1][2]` 紧邻或 `...方法[1]，另一种方法[2]` 同句禁止。

### 正例（独立句）
```
刘美琼(2024)以福建茶园为样本分析生态管理的边际效益[1]。申玲芝(2024)对福建安溪茶园的碳储量进行评估[2]。
```

### 反例（复合句多引用）
```
刘美琼(2024)分析了规模效益[1]；申玲芝(2024)评估了碳储量[2]。
```

### 改写
- 用句号 `。` 替换连接两个引用从句的 `；`
- 同句出现 `[N]，[M]` 时拆为两句

### 为什么
每个引用应独立承担其论断；多引用聚集稀释归属，且查重/AI 检测工具识别为 "citation farming"。

## C.4 1.1-1.2 章节禁引（hook G 系硬检查）

**本科毕业论文**正文首个引用**不得早于** `1.3 国内外研究现状`。

### 规则
- C.4.1 `1.1 研究背景` 不含 `[N]`——是作者对问题空间的自主陈述
- C.4.2 `1.2 研究意义` 不含 `[N]`——是作者对动机和贡献的陈述
- C.4.3 首个 `[1]` 出现在 `1.3.1 国内研究现状`

### 反例
- 1.2 引 `刘美琼(2024)...[1]` → 移除引用并改写 1.2，或将该论述移到 1.3.1

> 此规则适用本科论文。硕士/博士可在 1.1-1.2 引用，但需在 progress.md → Meta.Type 标注论文类型。

## C.5 文献编号唯一（hook G 系硬检查）

每个文献编号 `[N]` 在正文中**只能出现一次**。重复引用（同一 `[N]` 在 1.2 和 1.3.1 都出现）违规。

### 为什么
重复同一文献跨节常见原因：(a) 作者用一篇文献撑多个独立论点（论证不力），(b) 参考文献库太薄。两者都是评审会标记的质量问题。

### 同作者多处引用的处理
- 选项 A：第二处换用同作者另一篇文献
- 选项 B：把两处讨论合并到一个位置
- 选项 C：第二处转述论点，无引用（仅当该论点已在节内成为常识背景时）

---

## C.6 近 5 年文献（hook G 系硬检查）

所有文献**必须**在近 5 年内（含当年）。当前年 `Y`，可接受范围 `[Y-5, Y]`。早于 `Y-5` 的文献禁止，**例外**：经典奠基文献（如 Codd 1970）且使用必要性已论证。

### 例
当前 2026 → 接受范围 2021-2026。2017 年文献必须替换为 2021+ 同主题文献。

### 推荐近期来源
- MDPI Agriculture/Agronomy/Sensors（CC-BY 开放获取，便于核实）
- IEEE Access
- 高影响中文期刊（《中国农业科学》《农业工程学报》《中国茶叶》），2022 年起

---

## C.7 文献来源类型限制

下列来源**不得作为参考文献**：
- 网站资料（网页链接、博客、在线文档）—— 权威性不确定
- 内部资料 —— 读者无法验证
- 个人通讯 —— 读者无法验证
- 报纸 —— 非学术来源
- 未公开发表文章 —— 未经同行评审

### 允许的来源类型
仅以下五类（GB/T 7714 标识符）：
- `[J]` 期刊论文
- `[M]` 专著
- `[C]` 会议论文集
- `[D]` 学位论文
- `[S]` 标准
- `[P]` 专利

---

## C.8 GB/T 7714-2015 条目格式

参考文献列表条目格式如下。每类的标识符 `[J]`、`[M]` 等是必需的。

### C.8.1 期刊论文 [J]
```
[序号] 作者. 题名[J]. 刊名, 出版年, 卷(期): 起止页码.
```
例：
```
[1] 张三, 李四. 基于深度学习的文本分类研究[J]. 计算机学报, 2023, 46(3): 512-525.
[2] Wang Y, Liu Z. A survey of natural language processing[J]. Journal of Computer Science, 2022, 48(2): 100-115.
```

### C.8.2 专著 [M]
```
[序号] 作者. 书名[M]. 版次. 出版地: 出版者, 出版年: 引文页码.
```
例：
```
[3] 王五. 现代教育学导论[M]. 2版. 北京: 高等教育出版社, 2021: 45-67.
```

### C.8.3 学位论文 [D]
```
[序号] 作者. 题名[D]. 保存地: 保存单位, 年份.
```
例：
```
[4] 赵六. 人工智能在医疗诊断中的应用研究[D]. 北京: 清华大学, 2023.
```

### C.8.4 会议论文 [C]
```
[序号] 作者. 题名[C]//会议名称. 出版地: 出版者, 出版年: 起止页码.
```

### C.8.5 标准 [S]
```
[序号] 标准编号 标准名称[S]. 出版地: 出版者, 出版年.
```

### C.8.6 专利 [P]
```
[序号] 申请人. 专利题名: 专利国别, 专利号[P]. 公告日期.
```

### C.8.7 报纸 [N]（如已不再禁用，按 C.7 规则该类型已被排除）
仅在导师特别允许时使用。

## C.9 条目编写规则

### C.9.1 作者姓名
- 中文作者：全名（不缩写）
- 西文作者：`Surname Initial.`（姓在前、名缩写）
- 多作者：≤3 全部列出；>3 列前 3 后跟 `, 等`（中文）或 `, et al`（英文）

### C.9.2 编号
- 按正文首次出现顺序递增（与 C.1 一致）

### C.9.3 一致性
- 全文所有条目格式必须统一

### C.9.4 可验证性
- 每条引用必须可独立检索验证 —— **禁止编造**（与 A.3.3 一致）

---

## C.10 引用风格小结

正文内引用：`研究表明该方法的准确率达到95%以上[1]。`
作者提及：`刘美琼（2024）对生态管理做了系统分析[2]。`
区间引用：`多项研究证实了这一结论[2-4]。`（仅当 [2]、[3]、[4] 同一立场，且 C.5 编号唯一规则下使用区间需谨慎）
